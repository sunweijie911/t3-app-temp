# 换电套餐前端展示模块 — 产品需求文档（PRD）

> 版本：v1.0 | 日期：2026-03-19

---

## 1. 项目概述

### 1.1 背景

为申通内部商城新增「换电套餐」展示页面。目前合作的换电公司包括智租换电、铁塔换电、小哈换电，未来可能扩展更多合作方。消费者通过该页面浏览套餐详情，对比选购后跳转至对应第三方平台完成购买。

> **定位说明**：本模块为**纯展示 + 外跳**页面，仅负责套餐信息展示和购买跳转，实际购买行为在第三方平台（支付宝小程序/网页/APP）完成，本系统不涉及订单、支付等交易流程。

### 1.2 目标用户

| 角色 | 说明 |
|------|------|
| 消费者 | 申通内部商城所有用户，通过钉钉或浏览器访问 |
| 运营人员 | 后台管理套餐内容的编辑、上下架 |

### 1.3 业务目标

- 为申通员工提供清晰直观的换电套餐对比与购买入口
- 运营人员可自主维护套餐内容，无需开发介入
- 支持多家换电公司、多种电池规格的灵活展示

## 2. 访问与部署要求

| 维度 | 说明 |
|------|------|
| 访问对象 | 申通内部商城所有消费者均可访问，**无需登录** |
| 部署方式 | 需部署至服务器，提供详细访问地址 |
| 钉钉生态 | 支持钉钉内嵌 H5 页面跳转访问 |
| 适配终端 | **仅手机端**，页面内容纵向分布 |
| 跳转目标 | 点击「立即购买」后跳转至支付宝小程序 / 网页 / APP |

## 3. 前台展示页（消费者端）

### 3.1 信息字段说明

以下为每个套餐需展示的字段及其规则：

| 序号 | 字段 | 展示规则 | 是否可由后台编辑 |
|------|------|---------|----------------|
| 1 | **商品实物图** | 套餐顶部大图展示 | 是（本地上传图片） |
| 2 | **换电公司** | 公司品牌名称 | 是 |
| 3 | **商品标题** | 套餐名称，如「智租×申通专属包月套餐」 | 是 |
| 4 | **商品价格** | 包含「划线价」（原价，删除线样式）和「最低销售价」（实际价格，醒目展示） | 是 |
| 5 | **套餐内容** | 电池型号 + 对应价格，多规格（一般 2 个）**平行横向展示** | 是（可增删规格） |
| 6 | **押金方式** | 默认显示「芝麻信用抵押金」 | 是（预填默认值，可修改） |
| 7 | **区域限制** | 纯文本展示，内容较长时支持换行显示 | 是 |
| 8 | **购买须知** | 默认显示「上海仅限48V，60V慎拍」 | 是（预填默认值，可修改） |
| 9 | **套餐有效期** | 时间段展示（起止日期） | 是 |
| 10 | **立即购买** | 卡片底部购买按钮，同步显示最低销售价 | 价格自动同步，跳转链接可编辑 |

### 3.3 页面形式说明

- 所有套餐在**同一页面**内，以**卡片列表**形式纵向排列，每个套餐为独立卡片
- 每张卡片包含上述 3.2 布局中的完整信息
- 多个套餐之间支持排序（后台设置排序权重）

### 3.4 交互说明

| 交互点 | 行为 |
|--------|------|
| **区域限制** | 纯文本直接展示，内容较长时自动换行，无需交互 |
| **立即购买** | 跳转至对应换电公司的购买页面（支付宝小程序/网页/APP） |
| **套餐规格** | 仅展示，不可交互选择 |

## 4. 后台管理页（运营端）

### 4.1 套餐列表管理

运营人员可在后台查看所有套餐，并进行以下操作：

| 操作 | 说明 |
|------|------|
| 新建套餐 | 填写完整信息后创建新的套餐 |
| 编辑套餐 | 修改已有套餐的任意可编辑字段 |
| 上架 / 下架 | 控制套餐在前台是否展示 |
| 删除套餐 | 删除前需二次确认 |
| 调整排序 | 控制套餐在前台的展示顺序 |

### 4.2 编辑表单字段

| 字段 | 输入方式 | 默认值 | 备注 |
|------|---------|--------|------|
| 商品实物图 | 图片上传（本地文件） | - | 支持预览和替换 |
| 换电公司 | 文本输入 | - | 如：智租换电、铁塔换电、小哈换电 |
| 商品标题 | 文本输入 | - | 如：智租×申通专属包月套餐 |
| 划线价 | 数字输入 | - | 原价 |
| 最低销售价 | 数字输入 | - | 实际展示的售价 |
| 套餐规格 | **动态行** | 默认 2 行 | 每行填写：电池型号 + 对应价格，支持增删行 |
| 押金方式 | 文本输入 | 芝麻信用抵押金 | 预填默认值，可修改 |
| 区域限制 | 文本输入 | - | 纯文本，支持换行（如：全国、仅上海、66个城市） |
| 购买须知 | 文本输入 | 上海仅限48V，60V慎拍 | 纯文本，预填默认值，可修改 |
| 套餐有效期 | 日期范围选择 | - | 开始日期 ~ 结束日期 |
| 购买跳转链接 | URL 输入 | - | 跳转至支付宝小程序/网页/APP 的链接 |
| 排序权重 | 数字输入 | 0 | 数字越小越靠前 |
| 是否上架 | 开关 | 开启 | 控制前台展示 |

## 7. 钉钉跳转支付宝小程序 — 技术调研结论

### 结论：可以实现，但需使用钉钉 JSAPI

钉钉内置 WebView **不支持**直接通过 `<a>` 标签或 `window.location.href` 打开 `alipays://` 自定义 scheme。必须通过钉钉提供的 JS 桥接 API（`dd.openLink`）来完成跳转。钉钉与支付宝同属阿里系，`dd.openLink` 已支持打开 `alipays://` 协议。

### 推荐方案

| 方案 | 说明 | 适用场景 |
|------|------|---------|
| **`dd.openLink` + `alipays://` scheme**（主方案） | 通过钉钉 JSAPI 打开支付宝 scheme 链接，直接唤起支付宝并跳转指定小程序/页面 | 钉钉内嵌 H5（用户已装支付宝） |
| **`https://ds.alipay.com/?scheme=` 中间页**（降级方案） | 非钉钉环境或 JSAPI 不可用时，通过支付宝官方中间页跳转 | 普通浏览器访问 |
| **展示小程序二维码**（兜底方案） | 用户手动打开支付宝扫码 | 以上方案均失败时 |

### JSAPI 申请与使用前提

- **需要企业认证**：在 [钉钉开放平台](https://open.dingtalk.com/) 创建应用前，企业须完成钉钉企业认证（审核约 3 个工作日）
- **主体限制**：JSAPI 面向已认证的企业组织，暂不支持个人主体。个人开发者可用测试账号调试，但正式发布需企业主体
- **申请流程**：登录钉钉开放平台 → 创建企业内部应用 → 添加「网页应用」能力 → 配置权限管理 → 获取 `corpId`、`agentId`、`AppKey`、`AppSecret` → 发布应用
- **鉴权文档**：[JSAPI 鉴权 - 钉钉开放平台](https://open.dingtalk.com/document/orgapp/jsapi-authentication)
- **JSAPI 总览**：[H5 微应用 JSAPI 总览](https://open.dingtalk.com/document/orgapp-client/jsapi-overview)

### 注意事项
- 支付宝 scheme 中的 `query` 参数须 `encodeURIComponent` 编码
- 用户手机须已安装支付宝 App，否则 scheme 跳转会失败，需做降级处理
- iOS 与 Android 行为可能有差异，需两端实测验证
