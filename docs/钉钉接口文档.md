## 前置：获取免登授权码（authCode）

> 参考文档：[requestAuthCode - 钉钉开放平台](https://open.dingtalk.com/document/development/jsapi-request-auth-code)

免登授权码通过钉钉客户端 JSAPI 在**前端**获取，再传给后端调用 LINK 网关接口换取用户信息。

### 安装

```bash
npm install dingtalk-jsapi --save
```

或 CDN 引入：

```html
<script src="https://g.alicdn.com/dingding/open-develop/1.9.0/dd.js"></script>
```

### 调用方式

此 JSAPI 无需 `dd.config` 鉴权即可调用。

```javascript
import * as dd from 'dingtalk-jsapi';

dd.ready(function() {
  dd.runtime.permission.requestAuthCode({
    corpId: 'ding12345xxx', // 企业 CorpID
    onSuccess: function(info) {
      // info.code 即为免登授权码（authCode）
      console.log(info.code);
    }
  });
});
```

### 参数说明

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| corpId | string | 是 | 企业 CorpID，在[钉钉开发者后台](https://open-dev.dingtalk.com/)右上角获取 |

> **corpId 获取方式**：第三方企业应用可在微应用首页 URL 中使用 `$CORPID$` 占位符，钉钉容器会自动替换为当前用户的企业 corpId。
> 例如：`https://www.dingtalk.com?corpId=$CORPID$`

### 注意事项

- 此 JSAPI **只能在钉钉客户端内调用**，浏览器中无效
- 可通过 `navigator.userAgent.includes('DingTalk')` 判断是否在钉钉环境
- 免登授权码**有效期 5 分钟**，且**只能使用一次**

### 完整免登流程

1. **前端**：调用 `dd.requestAuthCode` 获取 `authCode`
2. **后端**：用 `authCode` 调用 `GET_USER_INFO_BY_AUTHCODE`（见下方接口 1）获取 `userid`
3. **后端**：用 `userid` 调用 `DINGTALK_USER_INFO_GET`（见下方接口 2）获取用户详情

## 1. 免登码获取钉钉信息

- **API 名称**：`GET_USER_INFO_BY_AUTHCODE`
- **请求方式**：`POST`

### 请求参数

| 名称 | 类型 | 是否必填 | 描述 | 示例 |
|------|------|---------|------|------|
| authCode | string | 是 | 免登码 | `74befcaddd4a3c02a05d79e07afc04df` |

**请求示例：**

```json
{
  "authCode": "74befcaddd4a3c02a05d79e07afc04df"
}
```

### 响应参数

| 名称 | 类型 | 是否必填 | 描述 | 示例 |
|------|------|---------|------|------|
| success | boolean | 是 | 是否成功 | `true` |
| errorCode | string | 是 | 错误编码 | `000` |
| errorMsg | string | 是 | 错误信息 | `Error Msg Content` |
| data | object | 否 | 用户信息 | 见下方示例 |

**响应示例：**

```json
{
  "success": "true",
  "errorCode": "000",
  "data": {
    "name": "王**",
    "userid": "024************912"
  }
}
```

### data 字段

| 名称 | 类型 | 描述 |
|------|------|------|
| name | string | 用户姓名 |
| userid | string | 用户 ID |

---

## 2. 根据 userId 获取用户部分信息

- **API 名称**：`DINGTALK_USER_INFO_GET`
- **请求方式**：`POST`
- **返回信息**：姓名、手机号、部门、职位、工号

### 请求参数

| 名称 | 类型 | 是否必填 | 描述 | 示例 |
|------|------|---------|------|------|
| content.userId | string | 是 | 钉钉用户 ID | `136060544730526576` |

**请求示例：**

```json
{
  "content": {
    "userId": "136060544730526576"
  }
}
```

### 响应参数

| 名称 | 类型 | 是否必填 | 描述 | 示例 |
|------|------|---------|------|------|
| success | string | 是 | 是否成功 | `true` |
| errorCode | string | 是 | 错误编码 | `000` |
| errorMsg | string | 是 | 错误信息 | `Error Msg Content` |
| data | object | 否 | 用户信息 | 见下方示例 |

**响应示例：**

```json
{
  "success": "true",
  "errorCode": "000",
  "errorMsg": "Error Msg Content",
  "data": {
    "name": "祝兴奇",
    "mobile": "13323333333",
    "position": "神仙",
    "department": "[88888888,666666]",
    "jobNumber": "68686868"
  }
}
```

### data 字段

| 名称 | 类型 | 描述 |
|------|------|------|
| name | string | 姓名 |
| mobile | string | 手机号 |
| position | string | 职位 |
| department | string | 部门 ID 列表 |
| jobNumber | string | 工号 |
